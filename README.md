# Estilo Livre — Barbearia

Projeto educacional com Bootstrap 5, layout responsivo, navbar, Grid System, cards, carousel e formulário com validação no navegador.

## Como visualizar
Abra `index.html` no navegador. O Bootstrap é carregado por CDN, então precisa de internet para os componentes interativos.

Os preços, endereço, telefone e depoimentos são fictícios. O formulário não envia dados a um servidor.
